## Recursion

### What is Recursion

> [!definition] Recursion
> A technique where a method **calls itself** to solve a problem by breaking it down into smaller subproblems.

The idea is simple: if the problem is small enough, solve it directly. Otherwise, reduce it to a smaller version of the same problem and call yourself.

> [!tip] Two things every recursive method needs
> 1. **Base case:** the condition where recursion stops (prevents infinite recursion)
> 2. **Recursive case:** the part where the method calls itself with a smaller input

---

### Base Case and Recursive Case

> [!warning] Without a base case, you get infinite recursion
> And that means a `StackOverflowError`. The call stack fills up and the program crashes. Always define when to stop.

> [!example] Simple Countdown
> ```java
> public static void countdown(int n) {
>     if (n <= 0) {                  // base case
>         System.out.println("Go!");
>     } else {
>         System.out.println(n);
>         countdown(n - 1);          // recursive case
>     }
> }
>
> countdown(3);
> // Output:
> // 3
> // 2
> // 1
> // Go!
> ```

---

### How the Call Stack Works

Every time a method is called, Java pushes a new **stack frame** onto the call stack. Each frame holds its own local variables.

> [!info] Stack Frame Walkthrough: `factorial(4)`
> ```
> factorial(4) → 4 * factorial(3)
>                    factorial(3) → 3 * factorial(2)
>                                       factorial(2) → 2 * factorial(1)
>                                                          factorial(1) → 1 (base case!)
>                                                      ← returns 1
>                                  ← returns 2 * 1 = 2
>                    ← returns 3 * 2 = 6
> ← returns 4 * 6 = 24
> ```
> Each call waits for the one below it to finish, then uses that result to compute its own answer.

### Classic Examples

#### Factorial

$n! = n \times (n-1) \times (n-2) \times \ldots \times 1$, with $0! = 1$.

> [!example] Factorial
> ```java
> public static int factorial(int n) {
>     if (n <= 1) return 1;          // base case
>     return n * factorial(n - 1);   // recursive case
> }
>
> factorial(5);   // 5 * 4 * 3 * 2 * 1 = 120
> ```

#### Fibonacci

$F(0) = 0$, $F(1) = 1$, and $F(n) = F(n-1) + F(n-2)$ for $n \geq 2$.

> [!example] Fibonacci
> ```java
> public static int fibonacci(int n) {
>     if (n <= 0) return 0;          // base case
>     if (n == 1) return 1;          // base case
>     return fibonacci(n - 1) + fibonacci(n - 2);  // recursive case
> }
>
> fibonacci(6);   // 8  (sequence: 0, 1, 1, 2, 3, 5, 8)
> ```

> [!warning] Fibonacci with recursion is slow
> Each call branches into two more calls, making it exponential, $O(2^n)$. For large values of $n$, use iteration or memoization instead.

#### Power

$x^n = x \times x^{n-1}$, with $x^0 = 1$.

> [!example] Power
> ```java
> public static double power(double base, int exp) {
>     if (exp == 0) return 1;
>     return base * power(base, exp - 1);
> }
>
> power(2, 10);   // 1024.0
> ```

#### Sum of Digits

> [!example] Sum of Digits
> ```java
> public static int digitSum(int n) {
>     if (n == 0) return 0;
>     return (n % 10) + digitSum(n / 10);
> }
>
> digitSum(1234);   // 1 + 2 + 3 + 4 = 10
> ```

### Recursion vs. Iteration

> [!abstract] Comparison
> | Aspect | Recursion | Iteration |
> |---|---|---|
> | Uses | Method calls itself | Loops (`for`, `while`) |
> | Memory | Uses call stack (more memory) | Uses loop variables (less memory) |
> | Readability | Often more elegant and concise | Can be more straightforward |
> | Risk | `StackOverflowError` if too deep | Infinite loop if condition never met |
> | Performance | Can be slower due to overhead | Usually faster |

> [!tip] When to use recursion
> Recursion shines for problems that are **naturally recursive** like trees, backtracking, divide-and-conquer, and mathematical sequences. For simple counting loops, iteration is usually better.

## Date and Time

### The java.time Package

Introduced in Java 8, the `java.time` package provides a modern API for handling dates and times. It replaces the older `java.util.Date` and `Calendar` classes which were... not great.

```java
import java.time.LocalDate;
import java.time.LocalTime;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
```

---

### LocalDate

Represents a date (year, month, day) without time.

> [!example] LocalDate Basics
> ```java
> LocalDate today = LocalDate.now();
> System.out.println(today);           // e.g., 2026-03-11
>
> LocalDate birthday = LocalDate.of(2007, 5, 15);
> System.out.println(birthday);        // 2007-05-15
> ```

> [!info] Useful LocalDate Methods
> | Method | Description |
> |---|---|
> | `now()` | Current date |
> | `of(year, month, day)` | Create a specific date |
> | `getYear()` | Returns the year |
> | `getMonth()` | Returns the month (as enum) |
> | `getMonthValue()` | Returns the month (as `int`, 1-12) |
> | `getDayOfMonth()` | Returns the day of the month |
> | `getDayOfWeek()` | Returns the day of the week (as enum) |
> | `plusDays(n)` | Adds days |
> | `minusMonths(n)` | Subtracts months |
> | `isLeapYear()` | Checks if it's a leap year |

> [!example] Working with LocalDate
> ```java
> LocalDate date = LocalDate.of(2026, 3, 11);
>
> date.getYear();         // 2026
> date.getMonthValue();   // 3
> date.getDayOfWeek();    // WEDNESDAY
>
> date.plusDays(10);       // 2026-03-21
> date.minusMonths(2);    // 2026-01-11
> date.isLeapYear();      // false
> ```

---

### LocalTime

Represents a time (hour, minute, second) without a date.

> [!example] LocalTime Basics
> ```java
> LocalTime now = LocalTime.now();
> System.out.println(now);              // e.g., 14:30:45.123456
>
> LocalTime alarm = LocalTime.of(7, 30);
> System.out.println(alarm);            // 07:30
>
> LocalTime precise = LocalTime.of(14, 30, 45);
> System.out.println(precise);          // 14:30:45
> ```

> [!info] Useful LocalTime Methods
> | Method | Description |
> |---|---|
> | `now()` | Current time |
> | `of(hour, minute)` | Create a specific time |
> | `of(hour, minute, second)` | With seconds |
> | `getHour()` | Returns the hour (0-23) |
> | `getMinute()` | Returns the minute |
> | `plusHours(n)` | Adds hours |
> | `minusMinutes(n)` | Subtracts minutes |

---

### LocalDateTime

Combines both date and time.

> [!example] LocalDateTime Basics
> ```java
> LocalDateTime now = LocalDateTime.now();
> System.out.println(now);  // e.g., 2026-03-11T14:30:45
>
> LocalDateTime event = LocalDateTime.of(2026, 6, 15, 18, 0);
> System.out.println(event);  // 2026-06-15T18:00
> ```

> [!tip] Extracting parts
> ```java
> LocalDateTime dt = LocalDateTime.now();
> dt.toLocalDate();    // just the date part
> dt.toLocalTime();    // just the time part
> ```

---

### DateTimeFormatter

Used to format dates and times into custom string patterns and to parse strings into date objects.

> [!abstract] Common Format Patterns
> | Pattern | Meaning | Example |
> |:---:|---|---|
> | `yyyy` | 4-digit year | 2026 |
> | `MM` | 2-digit month | 03 |
> | `dd` | 2-digit day | 11 |
> | `HH` | Hour (24-hour) | 14 |
> | `hh` | Hour (12-hour) | 02 |
> | `mm` | Minutes | 30 |
> | `ss` | Seconds | 45 |
> | `a` | AM/PM | PM |
> | `EEEE` | Day of week | Wednesday |
> | `MMMM` | Month name | March |

> [!example] Formatting Dates
> ```java
> LocalDate today = LocalDate.now();
> DateTimeFormatter fmt = DateTimeFormatter.ofPattern("MMMM dd, yyyy");
> System.out.println(today.format(fmt));   // March 11, 2026
>
> DateTimeFormatter fmt2 = DateTimeFormatter.ofPattern("MM/dd/yyyy");
> System.out.println(today.format(fmt2));  // 03/11/2026
> ```

> [!example] Formatting Date and Time
> ```java
> LocalDateTime now = LocalDateTime.now();
> DateTimeFormatter fmt = DateTimeFormatter.ofPattern("EEEE, MMMM dd yyyy hh:mm a");
> System.out.println(now.format(fmt));
> // e.g., Wednesday, March 11 2026 12:19 AM
> ```

> [!example] Parsing a String to a Date
> ```java
> String dateStr = "03/11/2026";
> DateTimeFormatter fmt = DateTimeFormatter.ofPattern("MM/dd/yyyy");
> LocalDate parsed = LocalDate.parse(dateStr, fmt);
> System.out.println(parsed);   // 2026-03-11
> ```

### Useful Date-Time Methods

> [!abstract] Handy Operations
> | Operation | Code |
> |---|---|
> | Days between two dates | `ChronoUnit.DAYS.between(date1, date2)` |
> | Check if before/after | `date1.isBefore(date2)`, `date1.isAfter(date2)` |
> | Check if equal | `date1.isEqual(date2)` |
> | Current timestamp | `LocalDateTime.now()` |
> | Add/subtract | `.plusDays()`, `.minusHours()`, `.plusMonths()`, etc. |

> [!example] Days Between Dates
> ```java
> import java.time.temporal.ChronoUnit;
>
> LocalDate start = LocalDate.of(2026, 1, 1);
> LocalDate end = LocalDate.of(2026, 12, 31);
>
> long days = ChronoUnit.DAYS.between(start, end);
> System.out.println(days + " days");   // 364 days
> ```
