## Why Use Methods

Methods let you break your program into smaller, reusable chunks. Instead of writing everything in `main`, you can organize your code into logical pieces.

> [!tip] Benefits
> - **Reusability:** Write once, call many times
> - **Readability:** Smaller methods are easier to understand
> - **Debugging:** Easier to find and fix bugs in isolated methods
> - **Modularity:** Each method handles one specific task

## Method Syntax

> [!info] General Syntax
> ```java
> modifier returnType methodName(parameterList) {
>     // method body
>     return value;  // only for value-returning methods
> }
> ```

> [!abstract] Parts of a Method
> | Part | Description |
> |---|---|
> | `modifier` | Access level (`public`, `private`, etc.) |
> | `returnType` | Type of value returned (`int`, `double`, `String`, `void`) |
> | `methodName` | The name you give the method (camelCase by convention) |
> | `parameterList` | Input values the method accepts (can be empty) |
> | `return` | Sends a value back to the caller |

## Void Methods

A `void` method performs an action but **doesn't return a value**.

> [!example] Void Method
> ```java
> public static void greet(String name) {
>     System.out.println("Hello, " + name + "!");
> }
>
> // Calling it:
> greet("Angelo");    // Output: Hello, Angelo!
> greet("Maria");     // Output: Hello, Maria!
> ```

> [!example] Void Method with No Parameters
> ```java
> public static void printLine() {
>     System.out.println("-------------------");
> }
>
> // Calling it:
> printLine();   // Output: -------------------
> ```

## Value-Returning Methods

These methods compute something and **return a result** to the caller.

> [!example] Value-Returning Method
> ```java
> public static int square(int num) {
>     return num * num;
> }
>
> // Calling it:
> int result = square(5);           // result = 25
> System.out.println(square(8));    // Output: 36... wait, 64
> ```

> [!example] Method Returning a double
> ```java
> public static double circleArea(double radius) {
>     return Math.PI * radius * radius;
> }
>
> // Calling it:
> double area = circleArea(7.5);
> System.out.printf("Area: %.2f%n", area);   // Area: 176.71
> ```

> [!warning] Return type must match
> If the method signature says `int`, you must return an `int`. Returning a `double` from an `int` method is a compile error.

## Parameters and Arguments

### Formal vs Actual Parameters

> [!definition] Parameters
> **Formal parameters** are the variables listed in the method declaration.
>
> **Actual parameters (arguments)** are the values you pass when calling the method.

> [!example] Formal vs Actual
> ```java
>                              // formal parameters
> public static int add(int a, int b) {
>     return a + b;
> }
>
> // actual parameters (arguments)
> int sum = add(3, 7);         // a = 3, b = 7
> ```

### Pass by Value

> [!info] Java is always pass by value
> When you pass a variable to a method, the method gets a **copy** of the value. Changes to the parameter inside the method do **not** affect the original variable.

> [!example] Pass by Value
> ```java
> public static void tryToChange(int x) {
>     x = 100;
>     System.out.println("Inside method: " + x);   // 100
> }
>
> public static void main(String[] args) {
>     int num = 5;
>     tryToChange(num);
>     System.out.println("After method call: " + num);  // 5 (unchanged!)
> }
> ```

## Method Overloading

You can define multiple methods with the **same name** as long as they have **different parameter lists** (different number or types of parameters).

> [!definition] Method Overloading
> When two or more methods in the same class share the same name but have different signatures (different parameter types or count).

> [!example] Overloaded Methods
> ```java
> public static int add(int a, int b) {
>     return a + b;
> }
>
> public static double add(double a, double b) {
>     return a + b;
> }
>
> public static int add(int a, int b, int c) {
>     return a + b + c;
> }
>
> // Java picks the right one based on arguments:
> add(2, 3);           // calls int version → 5
> add(2.5, 3.7);       // calls double version → 6.2
> add(1, 2, 3);        // calls three-parameter version → 6
> ```

> [!warning] Return type alone doesn't count
> Two methods that differ only in return type (but have the same name and parameter list) will cause a compile error. The parameter list must be different.

## Scope of Variables

> [!definition] Scope
> The **scope** of a variable is the region of the program where it can be accessed.

> [!abstract] Scope Rules
> | Declaration Location | Scope |
> |---|---|
> | Inside a method | Only accessible within that method (**local variable**) |
> | Inside a block (`{}`) | Only accessible within that block |
> | As a method parameter | Only accessible within that method |
> | As a class field | Accessible throughout the class |

> [!example] Scope Demo
> ```java
> public static void main(String[] args) {
>     int x = 10;   // x is local to main
>
>     if (x > 5) {
>         int y = 20;   // y is local to this if-block
>         System.out.println(x + y);  // works fine
>     }
>
>     // System.out.println(y);  // ERROR: y is out of scope here
> }
> ```

> [!warning] Same name, different scope
> You can have variables with the same name in different methods. They're completely independent.
> ```java
> public static void methodA() {
>     int count = 5;  // this count belongs to methodA
> }
>
> public static void methodB() {
>     int count = 10; // totally separate from methodA's count
> }
> ```

## Static Methods

All the methods in these notes use the `static` keyword. Here's why.

> [!info] What static means
> A `static` method belongs to the **class**, not to any specific object. You can call it without creating an instance.
>
> Since `main` is `static`, any method called directly from `main` also needs to be `static` (unless you create an object first).

> [!example] Static Method Calls
> ```java
> public class Calculator {
>     public static int multiply(int a, int b) {
>         return a * b;
>     }
>
>     public static void main(String[] args) {
>         int result = multiply(4, 5);  // direct call, no object needed
>         System.out.println(result);   // 20
>     }
> }
> ```

> [!tip] Math class methods are static
> That's why you can call `Math.pow(2, 3)` or `Math.sqrt(16)` directly without creating a `Math` object. They're all `static` methods.
