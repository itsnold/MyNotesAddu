## Relational Operators

Used to compare two values. The result is always a `boolean` (`true` or `false`).

> [!abstract] Relational Operators
> | Operator | Meaning |
> |:---:|---|
> | `==` | Equal to |
> | `!=` | Not equal to |
> | `>` | Greater than |
> | `<` | Less than |
> | `>=` | Greater than or equal to |
> | `<=` | Less than or equal to |

> [!warning] `==` vs `=`
> `==` is for comparison. `=` is for assignment. Mixing them up is one of the most common beginner mistakes.
> ```java
> int x = 5;
> if (x == 5)   // comparison: true
> if (x = 5)    // ERROR: this is assignment, not valid in a condition
> ```

---

## Logical Operators

Combine multiple boolean expressions into one.

> [!abstract] Logical Operators
> | Operator | Name | True when... |
> |:---:|---|---|
> | `!` | NOT | Operand is false |
> | `&&` | AND | Both operands are true |
> | `\|\|` | OR | At least one operand is true |

> [!info] Precedence
> `!` is evaluated first, then `&&`, then `||`.
>
> When in doubt, use parentheses to make things clear.

> [!example] Logical Operator Examples
> ```java
> int age = 20;
> boolean isStudent = true;
>
> (age >= 18) && isStudent       // true
> (age < 18) || isStudent        // true
> !(age >= 18)                   // false
> ```

---

## Short-Circuit Evaluation

Java evaluates logical expressions from left to right and **stops as soon as the result is determined**.

> [!tip] How it works
> - `&&`: If the left side is `false`, the right side is **never evaluated** (result is already `false`).
> - `||`: If the left side is `true`, the right side is **never evaluated** (result is already `true`).

> [!example] Short-Circuit in Action
> ```java
> int x = 0;
> if (x != 0 && 10 / x > 2)   // safe! 10/x never runs because x != 0 is false
> ```
> Without short-circuit evaluation, this would crash with a division by zero.

## Selection Structures

These let your program make decisions and execute different blocks of code based on conditions.

### The if Statement

The simplest selection structure. Executes a block only if the condition is `true`.

> [!info] Syntax
> ```java
> if (condition) {
>     // runs when condition is true
> }
> ```

> [!example] Basic if
> ```java
> int score = 85;
> if (score >= 75) {
>     System.out.println("You passed!");
> }
> ```

---

### The if-else Statement

Provides an alternative path when the condition is `false`.

> [!info] Syntax
> ```java
> if (condition) {
>     // runs when true
> } else {
>     // runs when false
> }
> ```

> [!example] if-else
> ```java
> int num = 7;
> if (num % 2 == 0) {
>     System.out.println("Even");
> } else {
>     System.out.println("Odd");
> }
> // Output: Odd
> ```

---

### The if-else if-else Chain

For checking multiple conditions. Only the **first** matching block runs.

> [!info] Syntax
> ```java
> if (condition1) {
>     // ...
> } else if (condition2) {
>     // ...
> } else if (condition3) {
>     // ...
> } else {
>     // default case
> }
> ```

> [!example] Grading System
> ```java
> int score = 82;
>
> if (score >= 90) {
>     System.out.println("A");
> } else if (score >= 80) {
>     System.out.println("B");
> } else if (score >= 70) {
>     System.out.println("C");
> } else {
>     System.out.println("F");
> }
> // Output: B
> ```

> [!warning] Order matters
> Conditions are checked top to bottom. Once a match is found, the rest are skipped entirely. So put your most specific or restrictive conditions first.

### Comparing Strings

> [!warning] Don't use `==` for Strings!
> `==` checks if two references point to the **same object**, not whether the content is the same. Use `.equals()` or `.equalsIgnoreCase()` instead.
>
> ```java
> String a = new String("hello");
> String b = new String("hello");
>
> a == b           // false (different objects)
> a.equals(b)      // true  (same content)
> ```

> [!info] String Comparison Methods
> | Method | What it does |
> |---|---|
> | `s1.equals(s2)` | `true` if content matches (case-sensitive) |
> | `s1.equalsIgnoreCase(s2)` | `true` if content matches (ignores case) |
> | `s1.compareTo(s2)` | Returns `0` if equal, negative if `s1 < s2`, positive if `s1 > s2` |

---

### The Ternary Operator

A shorthand for simple `if-else` expressions. It's an expression, not a statement, so it returns a value.

> [!info] Syntax
> ```java
> variable = (condition) ? valueIfTrue : valueIfFalse;
> ```

> [!example] Ternary Examples
> ```java
> int age = 20;
> String status = (age >= 18) ? "Adult" : "Minor";
> // status = "Adult"
>
> int a = 10, b = 20;
> int max = (a > b) ? a : b;
> // max = 20
> ```

---

### The switch Statement

Used when you're comparing a single variable against multiple constant values. Cleaner than a long `if-else if` chain for this case.

> [!info] Syntax
> ```java
> switch (expression) {
>     case value1:
>         // ...
>         break;
>     case value2:
>         // ...
>         break;
>     default:
>         // ...
> }
> ```

> [!warning] Don't forget break!
> Without `break`, execution **falls through** to the next case. This is a common source of bugs.

> [!example] switch Example
> ```java
> int day = 3;
> switch (day) {
>     case 1: System.out.println("Monday"); break;
>     case 2: System.out.println("Tuesday"); break;
>     case 3: System.out.println("Wednesday"); break;
>     case 4: System.out.println("Thursday"); break;
>     case 5: System.out.println("Friday"); break;
>     default: System.out.println("Weekend");
> }
> // Output: Wednesday
> ```

> [!tip] What types work with switch?
> `int`, `char`, `String` (since Java 7), and `enum`. You can't use `double`, `float`, or `boolean`.

## Repetition Structures

Loops let you repeat a block of code multiple times.

### The while Loop

Checks the condition **before** each iteration. If the condition is `false` from the start, the body never executes.

> [!info] Syntax
> ```java
> while (condition) {
>     // loop body
> }
> ```

> [!example] while Loop
> ```java
> int i = 1;
> while (i <= 5) {
>     System.out.print(i + " ");
>     i++;
> }
> // Output: 1 2 3 4 5
> ```

> [!warning] Infinite loops
> If the condition never becomes `false`, the loop runs forever. Always make sure something inside the loop changes the condition.
> ```java
> // BAD: infinite loop
> int x = 1;
> while (x > 0) {
>     System.out.println("forever...");
> }
> ```

---

### The for Loop

Best for when you know **how many times** to iterate. Initialization, condition, and update all go in one line.

> [!info] Syntax
> ```java
> for (initialization; condition; update) {
>     // loop body
> }
> ```

> [!example] for Loop
> ```java
> for (int i = 0; i < 5; i++) {
>     System.out.print(i + " ");
> }
> // Output: 0 1 2 3 4
> ```

> [!tip] for vs. while
> Every `for` loop can be rewritten as a `while` loop and vice versa. Use `for` when the number of iterations is known. Use `while` when you're looping until some condition changes.

---

### The do-while Loop

Checks the condition **after** each iteration. The body always executes **at least once**.

> [!info] Syntax
> ```java
> do {
>     // loop body
> } while (condition);
> ```

> [!example] do-while Loop
> ```java
> int num = 1;
> do {
>     System.out.print(num + " ");
>     num++;
> } while (num <= 5);
> // Output: 1 2 3 4 5
> ```

> [!tip] When to use do-while
> Use this when you need the loop body to run **at least once**, like prompting user input until it's valid:
> ```java
> int choice;
> do {
>     System.out.print("Enter 1-3: ");
>     choice = scanner.nextInt();
> } while (choice < 1 || choice > 3);
> ```

---

### Loop Control: break and continue

> [!abstract] Loop Control Statements
> | Statement | What it does |
> |---|---|
> | `break` | Immediately exits the loop entirely |
> | `continue` | Skips the rest of the current iteration and goes to the next one |

> [!example] break and continue
> ```java
> // break: stop at 5
> for (int i = 1; i <= 10; i++) {
>     if (i == 5) break;
>     System.out.print(i + " ");
> }
> // Output: 1 2 3 4
>
> // continue: skip 5
> for (int i = 1; i <= 10; i++) {
>     if (i == 5) continue;
>     System.out.print(i + " ");
> }
> // Output: 1 2 3 4 6 7 8 9 10
> ```

## Advanced Looping

### Nested Loops

A loop inside another loop. The inner loop completes all its iterations for each single iteration of the outer loop.

> [!example] Multiplication Table
> ```java
> for (int i = 1; i <= 3; i++) {
>     for (int j = 1; j <= 3; j++) {
>         System.out.printf("%4d", i * j);
>     }
>     System.out.println();
> }
> // Output:
> //    1   2   3
> //    2   4   6
> //    3   6   9
> ```

> [!example] Star Pattern
> ```java
> for (int i = 1; i <= 5; i++) {
>     for (int j = 1; j <= i; j++) {
>         System.out.print("* ");
>     }
>     System.out.println();
> }
> // Output:
> // *
> // * *
> // * * *
> // * * * *
> // * * * * *
> ```

---

### Sentinel-Controlled Loops

The loop keeps going until a special value (the **sentinel**) is entered. You don't know in advance how many iterations there will be.

> [!definition] Sentinel Value
> A predetermined value that signals the end of input. It should be a value that wouldn't normally appear in the data.

> [!example] Sentinel-Controlled Loop
> ```java
> Scanner scanner = new Scanner(System.in);
> int sum = 0;
> System.out.print("Enter a number (-1 to stop): ");
> int num = scanner.nextInt();
>
> while (num != -1) {
>     sum += num;
>     System.out.print("Enter a number (-1 to stop): ");
>     num = scanner.nextInt();
> }
> System.out.println("Total: " + sum);
> ```

---

### Flag-Controlled Loops

Use a `boolean` variable (the flag) to control when the loop stops.

> [!example] Flag-Controlled Loop
> ```java
> boolean found = false;
> int i = 2;
> int target = 17;
>
> // Check if target is prime
> while (i < target && !found) {
>     if (target % i == 0) {
>         found = true;
>     }
>     i++;
> }
>
> if (found) {
>     System.out.println(target + " is not prime.");
> } else {
>     System.out.println(target + " is prime.");
> }
> // Output: 17 is prime.
> ```

> [!tip] Flag vs. Sentinel
> - **Sentinel:** controlled by a special input value
> - **Flag:** controlled by a boolean condition you set in code
>
> Both are useful when the number of iterations isn't known upfront.
