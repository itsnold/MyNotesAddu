## What is JOptionPane

> [!definition] JOptionPane
> A class in the `javax.swing` package that provides pre-built dialog boxes for simple GUI interactions. Instead of using the console, you get pop-up windows.

It's useful when you want a friendlier interface without building a full GUI. You still write everything in `main`, you just get pop-ups instead of console text.

---

## Importing JOptionPane

```java
import javax.swing.JOptionPane;
```

> [!info] Note
> Unlike `Scanner`, `JOptionPane` is not in `java.util`. It's part of the Swing GUI library (`javax.swing`).

## showMessageDialog

Displays a message to the user. They just click OK to close it.

> [!info] Syntax
> ```java
> JOptionPane.showMessageDialog(null, "Your message here");
> ```
> The first argument is the parent component. Use `null` to center the dialog on the screen.

> [!example] Message Dialog
> ```java
> JOptionPane.showMessageDialog(null, "Hello, World!");
> ```
> This pops up a window with the message "Hello, World!" and an OK button.

You can also add a title and choose the icon type:

> [!info] Extended Syntax
> ```java
> JOptionPane.showMessageDialog(null, message, title, messageType);
> ```

> [!example] Custom Title and Icon
> ```java
> JOptionPane.showMessageDialog(null,
>     "File saved successfully!",
>     "Save",
>     JOptionPane.INFORMATION_MESSAGE);
> ```

## showInputDialog

Shows a dialog that asks the user to type something. Returns a `String`.

> [!info] Syntax
> ```java
> String input = JOptionPane.showInputDialog("Prompt message");
> ```

> [!example] Input Dialog
> ```java
> String name = JOptionPane.showInputDialog("What is your name?");
> JOptionPane.showMessageDialog(null, "Hello, " + name + "!");
> ```

> [!warning] Always returns a String
> Even if the user types a number, `showInputDialog` returns it as a `String`. You'll need to parse it if you want to do math with it.

> [!warning] Cancel and null
> If the user clicks **Cancel** or closes the dialog, the method returns `null`. You should check for this to avoid `NullPointerException`.
> ```java
> String input = JOptionPane.showInputDialog("Enter a number:");
> if (input != null) {
>     int num = Integer.parseInt(input);
>     // use num
> }
> ```

## showConfirmDialog

Asks the user a Yes/No/Cancel question. Returns an `int` indicating which button they clicked.

> [!info] Syntax
> ```java
> int choice = JOptionPane.showConfirmDialog(null, "Are you sure?");
> ```

> [!abstract] Return Values
> | Constant | Value | Meaning |
> |---|:---:|---|
> | `JOptionPane.YES_OPTION` | `0` | User clicked Yes |
> | `JOptionPane.NO_OPTION` | `1` | User clicked No |
> | `JOptionPane.CANCEL_OPTION` | `2` | User clicked Cancel |

> [!example] Confirm Dialog
> ```java
> int choice = JOptionPane.showConfirmDialog(null,
>     "Do you want to continue?");
>
> if (choice == JOptionPane.YES_OPTION) {
>     System.out.println("Continuing...");
> } else {
>     System.out.println("Stopped.");
> }
> ```

## Message Types and Icons

You can control the icon that appears in the dialog by specifying a message type.

> [!abstract] Message Type Constants
> | Constant | Description |
> |---|---|
> | `JOptionPane.PLAIN_MESSAGE` | No icon |
> | `JOptionPane.INFORMATION_MESSAGE` | Info icon (ℹ️) |
> | `JOptionPane.WARNING_MESSAGE` | Warning icon (⚠️) |
> | `JOptionPane.ERROR_MESSAGE` | Error icon (❌) |
> | `JOptionPane.QUESTION_MESSAGE` | Question icon (❓) |

> [!example] Using Different Icons
> ```java
> JOptionPane.showMessageDialog(null,
>     "Something went wrong!",
>     "Error",
>     JOptionPane.ERROR_MESSAGE);
>
> JOptionPane.showMessageDialog(null,
>     "Be careful with this action.",
>     "Warning",
>     JOptionPane.WARNING_MESSAGE);
> ```

## Parsing JOptionPane Input

Since `showInputDialog` always returns a `String`, you need to convert it before doing arithmetic.

> [!abstract] Parsing Methods
> | Target Type | Method |
> |---|---|
> | `int` | `Integer.parseInt(str)` |
> | `double` | `Double.parseDouble(str)` |
> | `float` | `Float.parseFloat(str)` |

> [!example] Parsing Input
> ```java
> String ageStr = JOptionPane.showInputDialog("Enter your age:");
> int age = Integer.parseInt(ageStr);
>
> String priceStr = JOptionPane.showInputDialog("Enter the price:");
> double price = Double.parseDouble(priceStr);
>
> JOptionPane.showMessageDialog(null,
>     "Age: " + age + "\nPrice: $" + String.format("%.2f", price));
> ```

## Putting It All Together

> [!example] Complete JOptionPane Program
> ```java
> import javax.swing.JOptionPane;
>
> public class TipCalculator {
>     public static void main(String[] args) {
>         String billStr = JOptionPane.showInputDialog("Enter your bill amount:");
>
>         if (billStr != null) {
>             double bill = Double.parseDouble(billStr);
>             double tip = bill * 0.15;
>             double total = bill + tip;
>
>             String message = String.format(
>                 "Bill:  $%.2f\nTip:   $%.2f\nTotal: $%.2f",
>                 bill, tip, total);
>
>             JOptionPane.showMessageDialog(null,
>                 message, "Tip Calculator",
>                 JOptionPane.INFORMATION_MESSAGE);
>         }
>
>         System.exit(0);
>     }
> }
> ```

> [!tip] System.exit(0)
> When using `JOptionPane`, it's good practice to call `System.exit(0)` at the end of `main`. This ensures all GUI threads are properly terminated. Without it, the program might not fully exit.
