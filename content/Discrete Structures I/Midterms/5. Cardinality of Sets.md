## Definition of Cardinality

We already know $|A|$ for finite sets (just count the elements). But what about infinite sets? Can one infinite set be "bigger" than another? The answer is yes, and the tool for comparing is the **bijection**.

> [!definition] Cardinality Comparison
> - **Equal cardinality** ($|A| = |B|$): there exists a **bijection** (one-to-one correspondence) from $A$ to $B$.
> - **Less than or equal** ($|A| \le |B|$): there exists an **injection** (one-to-one function) from $A$ to $B$.
> - **Strictly less than** ($|A| < |B|$): $|A| \le |B|$ and $A$, $B$ have *different* cardinalities.

> [!tip] WHY bijections?
> For finite sets, "same size" is obvious: just count. But you can't count to infinity. Instead, we pair elements up. If every element of $A$ can be matched with exactly one element of $B$ (and vice versa), then the sets have the "same number" of elements. That matching is a bijection.

## Countable vs Uncountable Sets

> [!definition] Countable and Uncountable
> - **Countable set:** either finite OR has the same cardinality as $\mathbb{Z}^+$ (the positive integers).
> - **Uncountable set:** not countable.
>
> When an infinite set is countable (i.e., *countably infinite*), its cardinality is denoted $\aleph_0$ ("aleph null," where $\aleph$ is the first letter of the Hebrew alphabet).

> [!info] How to show a set is countable
> An infinite set is countable if and only if you can **list its elements as a sequence** indexed by positive integers:
> $$a_1, a_2, a_3, \ldots$$
> This listing *is* the bijection: $f(n) = a_n$ maps $\mathbb{Z}^+$ to the set.

## Showing a Set is Countable

### Positive Even Integers

> [!example] $E = \{2, 4, 6, 8, \ldots\}$ is countable
> **Proof:** Define $f: \mathbb{Z}^+ \to E$ by $f(x) = 2x$.
>
> **One-to-one:** If $f(n) = f(m)$, then $2n = 2m$, so $n = m$. ✓
>
> **Onto:** Any even positive integer $t = 2k$ for some $k \in \mathbb{Z}^+$, so $f(k) = t$. ✓
>
> Since $f$ is a bijection, $|E| = |\mathbb{Z}^+| = \aleph_0$.

```tikz
\begin{document}
\begin{tikzpicture}[scale=0.9]
    % Top row: positive integers
    \foreach \i in {1,...,6} {
        \node[draw, circle, minimum size=0.7cm, fill=blue!10, font=\small] (top\i) at (1.5*\i, 1.2) {$\i$};
    }
    \node at (11.0, 1.2) {$\cdots$};
    \node[font=\small, blue] at (0, 1.2) {$\mathbb{Z}^+$};
    
    % Bottom row: even integers
    \foreach \i/\val in {1/2, 2/4, 3/6, 4/8, 5/10, 6/12} {
        \node[draw, circle, minimum size=0.7cm, fill=green!10, font=\small] (bot\i) at (1.5*\i, -0.5) {$\val$};
    }
    \node at (11.0, -0.5) {$\cdots$};
    \node[font=\small, green!60!black] at (0, -0.5) {$E$};
    
    % Arrows (bijection)
    \foreach \i in {1,...,6} {
        \draw[<->, thick, gray] (top\i) -- (bot\i);
    }
    
    \node[font=\footnotesize] at (5.5, -1.5) {$f(n) = 2n$: perfect one-to-one pairing};
\end{tikzpicture}
\end{document}
```

> [!tip] This is counterintuitive!
> The even numbers are a *proper subset* of the positive integers, yet they have the same cardinality. With infinite sets, a proper subset can be the same "size" as the original. This is actually one of the *defining properties* of infinite sets (Dedekind's characterization).

### The Set of All Integers

> [!example] $\mathbb{Z}$ is countable
> **Method 1 (Listing):** Arrange all integers into a sequence that alternates positive and negative:
> $$0, 1, -1, 2, -2, 3, -3, \ldots$$
> Every integer appears exactly once. Done.
>
> **Method 2 (Bijection):** Define $f: \mathbb{Z}^+ \to \mathbb{Z}$ by:
> - When $n$ is even: $f(n) = n/2$
> - When $n$ is odd: $f(n) = -(n-1)/2$
>
> This maps: $1 \mapsto 0$, $2 \mapsto 1$, $3 \mapsto -1$, $4 \mapsto 2$, $5 \mapsto -2$, ...

## The Real Numbers are Uncountable

This is one of the most important results in all of mathematics. It means $\mathbb{R}$ is "genuinely bigger" than $\mathbb{Z}$.

> [!abstract] Cantor's Diagonalization Argument
> **Theorem:** The set of real numbers $\mathbb{R}$ is uncountable.
>
> **Proof (by contradiction):**
>
> 1. **Assume** $\mathbb{R}$ is countable. Then the real numbers between 0 and 1 are also countable (subset of a countable set).
>
> 2. List them in order: $r_1, r_2, r_3, \ldots$
>    $$r_1 = 0.d_{11}d_{12}d_{13}d_{14}\ldots$$
>    $$r_2 = 0.d_{21}d_{22}d_{23}d_{24}\ldots$$
>    $$r_3 = 0.d_{31}d_{32}d_{33}d_{34}\ldots$$
>    $$\vdots$$
>
> 3. **Construct** a new real number $r = 0.r_1r_2r_3\ldots$ where:
>    - $r_i = 3$ if $d_{ii} \neq 3$
>    - $r_i = 4$ if $d_{ii} = 3$
>
> 4. This $r$ **differs from every $r_i$** in the $i$-th decimal place. So $r$ is NOT on our "complete" list.
>
> 5. **Contradiction!** We assumed we could list all reals in $(0,1)$, but we found one that's missing.
>
> 6. Since a set with an uncountable subset is itself uncountable, $\mathbb{R}$ is uncountable. $\blacksquare$

> [!tip] WHY does this work?
> The key insight: $r$ is **guaranteed** to differ from $r_1$ in the 1st digit, from $r_2$ in the 2nd digit, from $r_3$ in the 3rd digit, and so on. No matter how long your list is, the constructed number can't be on it. So no list can ever capture all the reals.

## Exercises

> [!example] Exercise 1: Is $\mathbb{Q}$ countable?
> **Yes.** The rational numbers are countable. You can arrange all positive rationals in a grid ($p/q$ at row $p$, column $q$) and then "snake" through the grid diagonally, skipping duplicates. This gives a listing $r_1, r_2, r_3, \ldots$ that hits every positive rational. Including negatives and zero, $\mathbb{Q}$ is still countable.

> [!example] Exercise 2: Countable or uncountable?
> **(a)** The set of all integers divisible by 5: $\{0, \pm5, \pm10, \pm15, \ldots\}$
>
> **Countable.** List as: $0, 5, -5, 10, -10, 15, -15, \ldots$
>
> **(b)** The set of real numbers between 0 and $\frac{1}{2}$
>
> **Uncountable.** The function $f(x) = x/2$ is a bijection from $(0,1)$ to $(0, 1/2)$, and we proved $(0,1)$ is uncountable. So $(0, 1/2)$ is uncountable too.
