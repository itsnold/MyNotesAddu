## Why Growth Rates Matter

When analyzing algorithms, we care about how the running time scales as input size $n$ grows. An algorithm that takes $3n$ steps on input of size $n$ is much better than one that takes $2^n$ steps, even though $2^n$ might be smaller for tiny inputs.

Growth-of-functions notation gives us a clean way to describe this scaling behavior without worrying about constant factors or small inputs.

---

## Big-O Notation

> [!definition] Big-O
> Let $f$ and $g$ be functions from integers (or reals) to reals. We say $f(x)$ is $O(g(x))$ if there exist constants $C > 0$ and $k$ such that:
> $$|f(x)| \le C|g(x)| \quad \text{for all } x > k$$
>
> Read as: "$f(x)$ is big-O of $g(x)$," meaning $g$ is an **upper bound** on the growth of $f$ (up to a constant factor, for large enough $x$).
>
> The constants $C$ and $k$ are called **witnesses**.

```tikz
\begin{document}
\begin{tikzpicture}[scale=0.65]
    \draw[->] (0,0) -- (8,0) node[right] {$x$};
    \draw[->] (0,0) -- (0,6) node[above] {$y$};
    
    % f(x) curve
    \draw[thick, blue, domain=0.5:7.5, smooth, samples=50] 
        plot (\x, {0.08*\x*\x + 0.3*\x + 0.2});
    \node[blue, font=\small] at (7, 3.5) {$f(x)$};
    
    % Cg(x) curve
    \draw[thick, red, domain=0.5:7.5, smooth, samples=50] 
        plot (\x, {0.12*\x*\x});
    \node[red, font=\small] at (6.5, 5.5) {$Cg(x)$};
    
    % k marker
    \draw[dashed, gray] (2.5, 0) -- (2.5, 5.5);
    \node[below, font=\small] at (2.5, 0) {$k$};
    
    % Shaded region
    \fill[green!10, opacity=0.5] (2.5,0) -- (2.5,5.5) -- (7.5,5.5) -- (7.5,0) -- cycle;
    
    \node[font=\footnotesize, align=center] at (5, 1) {$f(x) \le Cg(x)$\\for $x > k$};
\end{tikzpicture}
\end{document}
```

> [!info] Important points about Big-O
> - Once you find *one* pair of witnesses $(C, k)$, infinitely many pairs work (you can always increase $C$ or $k$)
> - The notation "$f(x) = O(g(x))$" is technically an abuse of the equals sign; it really means $f(x) \in O(g(x))$, since $O(g(x))$ is a *set* of functions
> - We usually drop the absolute value signs when dealing with functions that are always positive (like counts of operations)

### Using the Definition

> [!example] Example 1: $f(x) = x^2 + 2x + 1$ is $O(x^2)$
> **Proof:** For $x > 1$: $x < x^2$ and $1 < x^2$. So:
> $$x^2 + 2x + 1 \le x^2 + 2x^2 + x^2 = 4x^2$$
> Witnesses: $C = 4$, $k = 1$. $\blacksquare$

> [!example] Example 2: $7x^2$ is $O(x^3)$
> **Proof:** For $x > 7$: $7x^2 < x \cdot x^2 = x^3$.
> Witnesses: $C = 1$, $k = 7$. (Or $C = 7$, $k = 1$, since $7x^2 \le 7x^3$ for $x > 1$.) $\blacksquare$

> [!example] Example 3: $n^2$ is NOT $O(n)$
> **Proof by contradiction:** Suppose $n^2 \le Cn$ for all $n > k$. Dividing by $n$: $n \le C$ for all $n > k$. But $n$ grows without bound, so no constant $C$ can cap it. Contradiction. $\blacksquare$

### Big-O for Polynomials

> [!abstract] Theorem: leading term dominates
> If $f(x) = a_nx^n + a_{n-1}x^{n-1} + \dots + a_1x + a_0$ with $a_n \neq 0$, then:
> $$f(x) \text{ is } O(x^n)$$
>
> **Proof idea:** For $x > 1$, each term $|a_i|x^i \le |a_i|x^n$. Adding them up:
> $$|f(x)| \le (|a_n| + |a_{n-1}| + \dots + |a_0|) \cdot x^n$$
> So $C = |a_n| + |a_{n-1}| + \dots + |a_0|$ and $k = 1$ work as witnesses.

> [!tip] Takeaway
> For Big-O analysis, only the **highest-degree term** matters. Lower-order terms and constant coefficients can be ignored.

### Estimates for Common Functions

> [!info] Useful estimates
> - **Sum of first $n$ integers:** $1 + 2 + \dots + n \le n^2$, so it's $O(n^2)$
> - **Factorial:** $n! \le n^n$, so $n!$ is $O(n^n)$
> - **Log of factorial:** $\log(n!) \le n\log(n)$, so $\log(n!)$ is $O(n\log n)$

### Combining Functions

> [!definition] Sum and Product Rules
> If $f_1(x)$ is $O(g_1(x))$ and $f_2(x)$ is $O(g_2(x))$, then:
>
> **Sum rule:**
> $$(f_1 + f_2)(x) \text{ is } O\big(\max(|g_1(x)|, |g_2(x)|)\big)$$
> The bigger function dominates. In particular, if both are $O(g(x))$, their sum is also $O(g(x))$.
>
> **Product rule:**
> $$(f_1 \cdot f_2)(x) \text{ is } O(g_1(x) \cdot g_2(x))$$

## Big-Omega Notation (Lower Bound)

> [!definition] Big-$\Omega$
> $f(x)$ is $\Omega(g(x))$ if there exist constants $C > 0$ and $k$ such that:
> $$|f(x)| \ge C|g(x)| \quad \text{for all } x > k$$
>
> While Big-O provides an **upper bound**, Big-$\Omega$ provides a **lower bound**: $f$ grows *at least* as fast as $g$.

> [!tip] Relationship to Big-O
> $f(x)$ is $\Omega(g(x))$ if and only if $g(x)$ is $O(f(x))$.

> [!example] $8x^3 + 5x^2 + 7$ is $\Omega(x^3)$
> For all positive $x$: $8x^3 + 5x^2 + 7 \ge 8x^3$. So $C = 8$, $k = 0$.

## Big-Theta Notation (Tight Bound)

> [!definition] Big-$\Theta$
> $f(x)$ is $\Theta(g(x))$ if $f(x)$ is BOTH $O(g(x))$ AND $\Omega(g(x))$.
>
> Equivalently, there exist $C_1, C_2 > 0$ and $k$ such that:
> $$C_1|g(x)| \le |f(x)| \le C_2|g(x)| \quad \text{for all } x > k$$
>
> Read: "$f$ and $g$ have the **same order** of growth."

> [!warning] Big-O vs Big-$\Theta$
> Writers sometimes use Big-O when they actually mean Big-$\Theta$ (tight bound). Saying "$f$ is $O(n^2)$" only means "$n^2$ is an upper bound." Saying "$f$ is $\Theta(n^2)$" means "$f$ grows at the same rate as $n^2$," which is a stronger statement.

> [!example] Sum of first $n$ integers is $\Theta(n^2)$
> - **Upper bound ($O$):** $1 + 2 + \dots + n \le n^2$. So it's $O(n^2)$. ✓
> - **Lower bound ($\Omega$):** Sum the terms $> n/2$:
>   $$1 + 2 + \dots + n \ge \lceil n/2 \rceil + (\lceil n/2 \rceil + 1) + \dots + n \ge \frac{n}{2} \cdot \frac{n}{2} = \frac{n^2}{4}$$
>   So it's $\Omega(n^2)$ with $C = 1/4$. ✓
> - Both hold, so it's $\Theta(n^2)$. $\blacksquare$

> [!abstract] Corollary: Polynomials
> $f(x) = a_nx^n + \dots + a_0$ with $a_n \neq 0$ is $\Theta(x^n)$.

## Ordering Functions by Growth Rate

From slowest growing to fastest:

```tikz
\begin{document}
\begin{tikzpicture}[scale=0.7]
    % Growth rate ladder
    \foreach \i/\lab/\desc in {
        0/{$1$}/Constant,
        1/{$\log\log n$}/{},
        2/{$\log n$}/Logarithmic,
        3/{$(\log n)^c$}/Polylogarithmic,
        4/{$n$}/Linear,
        5/{$n \log n$}/Linearithmic,
        6/{$n^2$}/Quadratic,
        7/{$n^3$}/Cubic,
        8/{$2^n$}/Exponential,
        9/{$n!$}/Factorial
    } {
        \draw[thick, fill=blue!\i 0!white] (0, \i*0.8) rectangle (3, \i*0.8+0.6);
        \node[font=\small] at (1.5, \i*0.8+0.3) {\lab};
        \node[font=\footnotesize, gray, anchor=west] at (3.3, \i*0.8+0.3) {\desc};
    }
    \draw[->, ultra thick, red] (-0.8, 0) -- (-0.8, 7.7);
    \node[red, rotate=90, font=\small] at (-1.3, 3.5) {Growth rate};
\end{tikzpicture}
\end{document}
```

> [!info] Key dominance rules
> - Logarithms are always beaten by polynomials: $(\log n)^c$ is $O(n^d)$ for any positive $c, d$
> - Polynomials are always beaten by exponentials: $n^d$ is $O(b^n)$ for any $d$ and $b > 1$
> - Among exponentials: if $c > b > 1$, then $b^n$ is $O(c^n)$ but $c^n$ is NOT $O(b^n)$

## Exercises

> [!example] Exercise 1: Prove $3n + 7$ is $O(n)$
> **Solution:** For $n > 7$: $3n + 7 \le 3n + n = 4n$.
> Witnesses: $C = 4$, $k = 7$. So $3n + 7$ is $O(n)$. $\blacksquare$

> [!example] Exercise 2: Is $2^n$ $O(n^4)$?
> **Solution:** No. Exponentials always dominate polynomials. For any constants $C$ and $k$, eventually $2^n > Cn^4$. So $2^n$ is NOT $O(n^4)$.
>
> (In fact, $n^4$ is $O(2^n)$.)

> [!example] Exercise 3: Show $n^2 + 3n$ is $\Theta(n^2)$
> **Solution:**
> - **$O(n^2)$:** For $n > 3$: $n^2 + 3n \le n^2 + n \cdot n = 2n^2$. Witnesses: $C_2 = 2$, $k = 3$.
> - **$\Omega(n^2)$:** $n^2 + 3n \ge n^2$ for all $n \ge 0$. Witnesses: $C_1 = 1$, $k = 0$.
> - Both hold: $n^2 \le n^2 + 3n \le 2n^2$ for $n > 3$. So $n^2 + 3n$ is $\Theta(n^2)$. $\blacksquare$

> [!example] Exercise 4: Order these functions by growth rate
> $n \log n$, $2^n$, $n^3$, $\log n$, $n!$, $n^2$
>
> **Solution (slowest to fastest):**
> $$\log n \prec n \log n \prec n^2 \prec n^3 \prec 2^n \prec n!$$
