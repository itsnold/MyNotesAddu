## Symmetry in Mathematics

Symmetry is one of the most fundamental ideas in mathematics. A figure has **symmetry** if there exists a transformation that maps it onto itself.

> [!definition] Symmetry
> A **symmetry** of a figure is a rigid transformation (isometry) that maps the figure to itself. The set of all such symmetries forms a **symmetry group**.
> 
> The identity transformation (doing nothing) is always a symmetry.

> [!info] Types of Symmetry
> - **Rotational symmetry:** The figure looks the same after rotation by some angle less than $360°$
> - **Reflectional (bilateral) symmetry:** The figure looks the same after reflection across some line
> - **Translational symmetry:** The figure looks the same after shifting by some distance
> - **Glide reflection symmetry:** The figure looks the same after a combined slide and flip

## Rosette Patterns

A **rosette pattern** is a design with symmetry grouped around a single center point. Unlike frieze or wallpaper patterns, rosettes do **not** have translational symmetry — they stay in one place.

> [!definition] Rosette Pattern
> A pattern whose symmetry group contains only **rotations** and possibly **reflections** about a fixed center point.
> 
> There are exactly two families of rosette symmetry groups:
> - **Cyclic groups** $C_n$
> - **Dihedral groups** $D_n$

### Cyclic Groups ($C_n$)

> [!info] Cyclic Group $C_n$
> A rosette with **rotational symmetry only** (no reflection).
> 
> $C_n$ has exactly $n$ symmetries: rotations by $0°, \frac{360°}{n}, \frac{2 \times 360°}{n}, \ldots, \frac{(n-1) \times 360°}{n}$
> 
> - $C_1$: Only the identity (no visible symmetry)
> - $C_2$: $180°$ rotational symmetry (like the letter S)
> - $C_3$: $120°$ rotational symmetry (like a triskelion ☘)
> - $C_4$: $90°$ rotational symmetry (like a pinwheel)
> - $C_6$: $60°$ rotational symmetry (like a Star of David outline)

> [!example] Identifying $C_n$
> **How to determine $n$:**
> 
> Count how many times the figure "looks the same" as you rotate it through a full $360°$.
> 
> A fidget spinner with 3 arms: it looks identical at $0°$, $120°$, and $240°$. That gives $n = 3$, so it's $C_3$.
> 
> **Key test:** If the figure has NO mirror lines, it's cyclic ($C_n$), not dihedral.

### Dihedral Groups ($D_n$)

> [!info] Dihedral Group $D_n$
> A rosette with **both rotational AND reflectional symmetry**.
> 
> $D_n$ has $2n$ symmetries: $n$ rotations + $n$ reflections.
> 
> - $D_1$: 1 mirror line only (like the letter A)
> - $D_2$: 2 mirror lines + $180°$ rotation (like the letter H)
> - $D_3$: 3 mirror lines + $120°$ rotation (like an equilateral triangle)
> - $D_4$: 4 mirror lines + $90°$ rotation (like a square)
> - $D_6$: 6 mirror lines + $60°$ rotation (like a regular hexagon)
> - $D_n$: $n$ mirror lines + rotation by $360°/n$ (like a regular $n$-gon)

> [!example] Identifying $D_n$
> **How to determine $n$:**
> 
> Count the number of **mirror lines** (lines of reflectional symmetry). That count equals $n$.
> 
> A regular pentagon has 5 mirror lines (one through each vertex to the opposite midpoint), so it's $D_5$.
> 
> **Key test:** If the figure HAS mirror lines, it's dihedral ($D_n$).

> [!tip] Quick Classification
> 1. Does the figure have **mirror lines**?
>    - **No** → It's $C_n$ (cyclic). Count rotational positions.
>    - **Yes** → It's $D_n$ (dihedral). Count mirror lines.
> 2. The number $n$ tells you the smallest rotation angle: $360°/n$.

## Frieze Patterns

A **frieze pattern** is a pattern that repeats along a strip in one direction. Think of a decorative border, a fence, or a row of footprints.

> [!definition] Frieze Pattern
> A pattern with **translational symmetry** in exactly one direction. It extends infinitely (in theory) along a strip.
> 
> Every frieze pattern has a **minimal translation** — the smallest shift that maps the pattern onto itself.

### The Seven Frieze Groups

There are exactly **7 types** of frieze patterns, classified by which additional symmetries they have beyond translation.

> [!abstract] The 7 Frieze Groups
> | Name | Translation | Glide Refl. | Vertical Refl. | Horizontal Refl. | $180°$ Rotation | Example |
> |---|:---:|:---:|:---:|:---:|:---:|---|
> | **F1** (Hop) | ✓ | | | | | L L L L |
> | **F2** (Jump) | ✓ | | ✓ | | | V V V V |
> | **F3** (Sidle) | ✓ | ✓ | | | | b d b d |
> | **F4** (Spinning Hop) | ✓ | | | | ✓ | b q b q |
> | **F5** (Spinning Jump) | ✓ | ✓ | ✓ | | ✓ | b d q p |
> | **F6** (Step) | ✓ | ✓ | | ✓ | | b b b b |
> | **F7** (Spinning Sidle) | ✓ | ✓ | ✓ | ✓ | ✓ | H H H H |

> [!tip] How to Classify a Frieze Pattern
> Use this decision tree:
> 
> **Step 1:** Is there a **horizontal reflection** (across the length of the strip)?
> - **Yes** → Go to Step 2a
> - **No** → Go to Step 2b
> 
> **Step 2a (has horizontal reflection):**
> - Has vertical reflection? → **F7** (all symmetries)
> - No vertical reflection? → **F6** (step)
> 
> **Step 2b (no horizontal reflection):**
> - Has vertical reflection?
>   - **Yes:** Has $180°$ rotation? → **F5** / No rotation? → **F2**
>   - **No:** Has $180°$ rotation? → **F4** / Has glide reflection? → **F3** / Nothing else? → **F1**

> [!example] Classifying a Frieze
> **Pattern:** ... ↑ ↑ ↑ ↑ ↑ ... (a row of identical upward arrows)
> 
> **Working it out:**
> - Translation? Yes (shift one arrow spacing) ✓
> - Horizontal reflection? No (top and bottom of arrow are different) ✗
> - Vertical reflection? Yes (each arrow is vertically symmetric) ✓
> - $180°$ rotation? No (upside-down arrow looks different) ✗
> - Glide reflection? No ✗
> 
> **Classification: F2** (Jump) — translation + vertical reflections only.

> [!example] Another Classification
> **Pattern:** ... p q p q p q ... (alternating p and q)
> 
> **Working it out:**
> - Translation? Yes (two-letter period) ✓
> - Horizontal reflection? No ✗
> - Vertical reflection? No ✗
> - $180°$ rotation? Yes (rotating p gives q) ✓
> - Glide reflection? No ✗
> 
> **Classification: F4** (Spinning Hop) — translation + $180°$ rotation only.
