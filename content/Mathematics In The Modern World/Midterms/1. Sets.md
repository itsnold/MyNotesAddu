## What is a Set

In everyday life, we naturally group things together: the set of enrolled students, the set of months with 31 days, the set of prime numbers. Set theory gives us a formal language to work with these groupings.

> [!definition] Set
> A **set** is a well-defined collection of distinct objects, called its **elements** (or **members**).
>
> - Sets are denoted by **capital letters**: $A, B, U, X, \ldots$
> - Elements are denoted by **lowercase letters**: $a, b, x, \ldots$
> - Braces $\{\}$ enclose the elements of a set

> [!abstract] Element Notation
> | Symbol | Read as | Meaning |
> |:---:|---|---|
> | $x \in A$ | "$x$ is in $A$" | $x$ **is** an element of set $A$ |
> | $x \notin A$ | "$x$ is not in $A$" | $x$ is **not** an element of set $A$ |
>
> **Examples:** If $A = \{1, 2, 3\}$, then $2 \in A$ is **true**, but $5 \in A$ is **false** (so $5 \notin A$).

The phrase "well-defined" is key: given any object, we must be able to say definitively whether it belongs to the set or not. "The set of tall people" is NOT a valid set because "tall" is subjective. "The set of enrolled AdDU students" IS valid because enrollment is a definite status.

> [!example] Classroom Example
> Let $U = \{x \mid x \text{ is an enrolled AdDU student}\}$
>
> Let $A = \{x \mid x \text{ is an AdDU student enrolled in class code 16-151}\}$
>
> Then $A \subseteq U$, since every student in that class is also an enrolled AdDU student.

> [!info] Key Properties
> 1. **No duplicates:** Each element appears at most once. Writing $\{1, 1, 2\}$ is the same as $\{1, 2\}$.
> 2. **No order:** $\{a, b, c\} = \{c, a, b\}$. The arrangement inside braces doesn't matter.
> 3. **Sets can contain sets:** $\{\{1, 2\}, \{3, 4\}, 5\}$ is a perfectly valid set with 3 elements.

## Writing a Set

There are **three methods** to describe which elements belong to a set.

### Method 1: Roster Method

The **listing method** which is to simply enumerate all elements between curly braces, separated by commas. Use ellipses ($\ldots$) when the pattern is clear.

> [!example] Roster Method Examples
> - Set of vowels: $V = \{a, e, i, o, u\}$
> - Months starting with "M": $M = \{\text{March}, \text{May}\}$
> - Odd numbers from 1 to 9: $O = \{1, 3, 5, 7, 9\}$
> - Even positive integers: $E = \{2, 4, 6, 8, \ldots\}$

> [!example] Classic Illustration: Letters of "MISSISSIPPI"
> **Problem:** Write the set of all distinct letters in the word "MISSISSIPPI".
>
> Scanning: M, I, S, S, I, S, S, I, P, P, I. Collect distinct, drop duplicates.
>
> **Answer:** $X = \{M, I, S, P\}$
>
> The set has **4 elements**, even though the word has 11 letters. Duplicates are ignored.

### Method 2: Rule Method (Descriptive Method)

Describe the set **in words** by stating the rule or property that all members share. This is the most natural, everyday way to define a set.

> [!abstract] Rule Method
> State the defining property of the set in plain language inside braces:
> $$A = \{\text{description of members}\}$$

> [!example] Rule Method Examples
> - $V = \{$vowels of the English alphabet$\}$
> - $P = \{$prime numbers$\}$
> - $M = \{$months of the year with exactly 30 days$\}$ = $\{$April, June, September, November$\}$
> - $A = \{$AdDU students enrolled in class code 16-151$\}$
> - $E = \{$positive even integers$\}$

The rule method is most useful when the set is well-understood conceptually but might be awkward to write in formal notation. A limitation is that it can be vague if the rule is open to interpretation. That's why we also have set-builder notation.

### Method 3: Set-Builder Notation

The **formal method** where you describe the rule using mathematical symbols. This is the most rigorous and is required for sets you cannot list or describe easily in words.

> [!abstract] Set-Builder Notation
> $$S = \{x \mid P(x)\}$$
>
> Read: "the set of all $x$ **such that** $P(x)$ is true."
>
> The vertical bar $\mid$ (or colon $:$) means "such that."

> [!example] Set-Builder Examples
> - $E = \{x \mid x \text{ is an even positive integer}\}$
> - $P = \{x \in \mathbb{Z}^+ \mid x \text{ is prime}\}$
> - $A = \{x \in \mathbb{R} \mid x^2 < 9\}$: the set of reals strictly between $-3$ and $3$
> - $A = \{x \mid x \text{ is an AdDU student in class 16-151}\}$

> [!tip] Comparison: All Three Methods
> | Method | Form | Best for |
> |---|---|---|
> | **Roster** | $\{1, 3, 5, 7, 9\}$ | Small, finite sets |
> | **Rule** | $\{$odd numbers from 1–9$\}$ | Everyday descriptions |
> | **Set-Builder** | $\{x \in \mathbb{Z}^+ \mid x < 10, x \text{ odd}\}$ | Infinite or formally defined sets |

## Special Sets

### The Universal Set

> [!definition] Universal Set
> The **universal set** $U$ is the set containing **all objects currently under consideration**. Every other set in the discussion is a subset of $U$.
>
> The universal set depends entirely on context. If we're talking about students, $U$ might be all AdDU students. If we're talking about numbers, $U$ might be all real numbers.

### The Empty Set

> [!definition] Empty Set
> The **empty set** (or **null set**) is the set with no elements at all. It is denoted $\emptyset$ or $\{\}$.

> [!warning] Common Confusion
> $\emptyset \neq \{\emptyset\}$
>
> - $\emptyset$ has **zero** elements. It's completely empty.
> - $\{\emptyset\}$ has **one** element, and that element happens to be the empty set itself.
>
> Think of it like the difference between an empty box and a box containing an empty box.

### Standard Number Sets

These number sets appear constantly in math. Every math student needs to recognize them on sight.

> [!info] Standard Number Sets
> | Symbol | Name | Elements |
> |:---:|---|---|
> | $\mathbb{N}$ | Natural numbers | $\{0, 1, 2, 3, \ldots\}$ |
> | $\mathbb{Z}$ | Integers | $\{\ldots, -2, -1, 0, 1, 2, \ldots\}$ |
> | $\mathbb{Z}^+$ | Positive integers | $\{1, 2, 3, \ldots\}$ |
> | $\mathbb{Q}$ | Rational numbers | All fractions $p/q$ where $p, q \in \mathbb{Z}$, $q \neq 0$ |
> | $\mathbb{I}$ | Irrational numbers | Non-terminating, non-repeating decimals ($\sqrt{2}, \pi, e$) |
> | $\mathbb{R}$ | Real numbers | All points on the number line ($\mathbb{Q} \cup \mathbb{I}$) |

> [!tip] The Number Set Hierarchy
> $$\mathbb{N} \subset \mathbb{Z}^+ \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$
>
> Natural numbers are a subset of positive integers, which are a subset of integers, and so on. Every level is "bigger" than the one before it.

## Subsets and Set Equality

### Subsets

> [!definition] Subset
> $A$ is a **subset** of $B$, written $A \subseteq B$, if **every element of $A$ is also in $B$**.
>
> Formal definition: $A \subseteq B \iff \forall x\,(x \in A \to x \in B)$

If $A \subseteq B$ but $A \neq B$ (meaning $B$ has at least one element $A$ doesn't), then $A$ is a **proper subset** of $B$, written $A \subset B$.

```tikz
\begin{document}
\begin{tikzpicture}[scale=0.85]
    \draw[thick, rounded corners=5pt] (-3.5,-2.5) rectangle (3.5,2.5);
    \node[anchor=north west] at (-3.4,2.4) {$U$};
    % B (larger)
    \draw[thick, fill=red!10] (0,0) circle (1.8);
    \node[red!70!black, font=\small\bfseries] at (1.5,1.5) {$B$};
    % A (smaller, proper subset)
    \draw[thick, fill=blue!20] (-0.2,-0.2) circle (0.9);
    \node[blue!80!black, font=\small\bfseries] at (-0.2,-0.2) {$A$};
    \node[font=\small] at (0,-3.0) {$A \subset B$ - $A$ is a proper subset of $B$};
\end{tikzpicture}
\end{document}
```

> [!tip] Two facts that always hold
> 1. $\emptyset \subseteq S$ for **every** set $S$: the empty set is a subset of everything. (vacuously true)
> 2. $S \subseteq S$ for **every** set $S$: every set is a subset of itself.
> 3. A set with $n$ elements has $2^n$ total **distinct** subsets. In math, "distinct" means different or not identical.

### Set Equality

> [!definition] Set Equality
> Two sets are **equal** if they contain exactly the same elements:
> $$A = B \iff (A \subseteq B) \land (B \subseteq A)$$
>
> To prove two sets are equal, prove each is a subset of the other.

> [!example] Equality vs. Not
> - $\{1, 2, 3\} = \{3, 1, 2\}$ ✓ (same elements, order irrelevant)
> - $\{1, 2, 3\} \neq \{1, 2, 3, 4\}$ ✗ (4 is in the right set but not the left)

## Cardinality

> [!definition] Cardinality
> The **cardinality** of a set $A$ is the number of distinct elements it contains, written $|A|$.
>
> - A set is **finite** if $|A| = n$ for some non-negative integer $n$.
> - A set is **infinite** if it has no finite number of elements.

> [!example] Cardinality Examples
> | Set | Cardinality |
> |---|:---:|
> | $\emptyset$ | $0$ |
> | $\{a, e, i, o, u\}$ | $5$ |
> | $\{M, I, S, P\}$ (from "MISSISSIPPI") | $4$ |
> | $\{\emptyset\}$ | $1$ |
> | $\mathbb{Z}$ | Infinite |

> [!warning] Cardinality traps
> - $|\emptyset| = 0$ but $|\{\emptyset\}| = 1$
> - The set $\{\{1,2\}, \{3,4\}, 5\}$ has cardinality **3**, not 5. Count elements, not what's inside elements.
